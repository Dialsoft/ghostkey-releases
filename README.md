# GhostKey

Stuck & phantom input detector for Windows, by Dialsoft LLC.

GhostKey watches every keyboard and mouse at the hardware level and tells you exactly which device sent each key press, click, scroll or movement. It flags stuck keys and buttons, keys stuck in Windows, bouncing (double-clicking) switches and devices that keep disconnecting. Its 30-second **Hands-Off Test** catches "ghost" input that arrives while nobody is touching anything.
