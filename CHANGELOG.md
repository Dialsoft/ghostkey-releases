# GhostKey release notes

## 1.1.0 (2026-11-01)
- New ribbon interface with Home, Settings, Share and Help tabs, matching the other Dialsoft tools.
- Automatic updates: GhostKey checks for a new version when it starts and every 6 hours. A yellow bar offers "Update now", the download is verified (SHA-256 checksum and version check), and GhostKey swaps itself in and restarts with your settings kept. You can turn automatic checks off on the Settings tab.
- Share tab: tell someone about GhostKey by email (with the download link or with the program attached), Gmail, Outlook.com, Facebook Messenger, WhatsApp, text message or Microsoft Teams, or copy the download link.
- Release notes: Help > Release Notes lists what changed in every version, and after an update GhostKey shows what's new automatically.
- Double-click any Event Log line to read its full text.
- All settings are on the Settings tab and still take effect immediately.

## 1.0.0 (2026-10-27)
- First release. Watches every keyboard and mouse at the hardware level and shows which device each key press, click, scroll or movement came from.
- Flags stuck keys and buttons, keys stuck in Windows, bouncing (double-clicking) switches, and devices that keep disconnecting.
- Hands-Off Test: finds input that arrives while nobody is touching anything, with plain-English advice on the likely cause.
- Spots software-generated input (remote control tools, macros, mouse jigglers).
- Save Log, device details, and detailed tooltips on every control.
